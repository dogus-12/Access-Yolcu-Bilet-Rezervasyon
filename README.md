# C# Bilet Kayıt Otomasyonu

Bu proje, yolcu ve bilet kayıt süreçlerini yönetmek amacıyla C# ve Windows Forms (WinForms) kullanılarak geliştirilmiş bir masaüstü otomasyon uygulamasıdır.

## 🛠 Özellikler
- **Bilet ve Yolcu Yönetimi:** Yeni bilet oluşturma, yolcu bilgilerini alma ve kayıt güncelleme.
- **Koltuk Seçimi:** Otobüs/sefer düzenine göre dinamik koltuk eşleştirmesi.
- **Veri Doğrulama:** Form girdilerinin doğrulanması ve dinamik liste güncellemeleri.

## 💻 Teknolojiler
- **Dil:** C#
- **Arayüz:** Windows Forms (.NET)
- **Veritabanı:** Microsoft Access / SQL Server
- **Geliştirme Ortamı:** Visual Studio

##  Kurulum ve Çalıştırma
1. Bu projeyi bilgisayarınıza kopyalayın:
   `git clone https://github.com/kullanici-adiniz/proje-adi.git`
2. `.sln` dosyasını Visual Studio ile açın.
3. `F5` tuşuna basarak projeyi çalıştırın.
